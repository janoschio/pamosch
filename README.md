# pamosch

Source of https://www.pamosch.com, served with GitHub Pages.

- `index.html`, `logo.svg` – start page.
- `planning/index.html` – generated by `python3 build.py` from `src/`.
- `src/` – page template and scheduling logic.
- `tests/schedule.test.js` – `node tests/schedule.test.js`.
- `supabase/migrations/` – database schema.
